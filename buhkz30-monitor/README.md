# Мониторинг обновлений 1С:Бухгалтерия для Казахстана 3.0

Бесплатная автоматическая проверка страницы релизов PRO1C и отправка уведомлений в Telegram через GitHub Actions.

## Секреты GitHub

В Settings → Secrets and variables → Actions должны быть созданы:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Токен не размещайте в файлах репозитория.

## Установка

Загрузите в корень репозитория файлы и папку `.github` из этого архива, сохранив структуру.

В Settings → Actions → General проверьте, что разрешены workflow permissions для записи содержимого репозитория (если GitHub попросит).

Откройте Actions и запустите workflow `Monitor 1C Kazakhstan Accounting 3.0` через Run workflow.

Первый запуск сохранит найденные записи как базу и отправит сообщение об активации. Старые релизы массово рассылаться не будут. Дальше workflow проверяет источник примерно раз в 30 минут.

## Источник и ограничения

Основной источник: https://pro1c.kz/update/?PRODUCT_ID=2006

Скрипт отслеживает строки именно продукта «Бухгалтерия 8 для Казахстана, ред. 3.0», включая видимые в карточке дополнения и ссылки «Все дополнения».

Это монитор публикаций, а не загрузчик обновлений. Доступ к скачиванию файлов обновлений регулируется официальной поддержкой 1С/ИТС. Разметка сайта может меняться; при ошибке workflow завершится с ошибкой, а состояние не будет обновлено.

## Проверка

После запуска откройте Actions → последний запуск → логи шага `Check releases and supplements`.
